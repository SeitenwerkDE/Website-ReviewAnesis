# ANESIS SOLTAU – Website

Inhalte (Adresse, Telefon, Öffnungszeiten, Links, Bilder, rechtliche Angaben) werden zentral in `src/config/restaurant.ts` gepflegt.

## Eingebundene Dienste (Cookie-Consent)
- Keine Drittanbieter-Skripte, kein Tracking, keine eingebetteten Karten.
- Schriften lokal über `@fontsource/cormorant-garamond` und `@fontsource/inter`.
- Google Maps nur als externer Link („Route planen“).
- Geplant: Google-Bewertungen serverseitig über die Google Places API (keine Browser-Verbindung zu Google).
